# ar-nenga2024


発光するマテリアルと宙に浮く床を用いて、「HAPPY NEW YEAR 2024」というテキストの3Dアニメーションを作成するThree.jsベースのプロジェクトです。

## 特徴
- カスタムの発光マテリアルを使用して「HAPPY NEW YEAR 2024」の3Dテキストを生成
- 回転と位置の変更によりテキストをアニメーション化
- 3Dシーンを引き立てるために、宙に浮く床と天井を作成
- ブルームのポストプロセスエフェクトを使用したバージョンを同梱

## 要件
本プロジェクトには、JavaScriptモジュールとWebGLをサポートするモダンWebブラウザが必要です。

## 使用方法
1. リポジトリをクローンします:
   ```
   git clone https://github.com/code4fukui/ar-nenga2024.git
   ```
2. WebブラウザでHTMLファイル（`index.html`、`logo.html`、または`bloom.html`）を開きます。

## データ / API
本プロジェクトでは、以下の外部ライブラリを使用しています:
- 3Dレンダリング用の [Three.js](https://threejs.org/)
- Three.jsのセットアップ用の [egxr.js](https://github.com/code4fukui/egxr.js)
- 3Dテキスト生成用の [createMeshIJFont.js](https://github.com/ichigojam/font)
